# GitHub Workflow

## Repository Setup
Repository name: SRMSS-ASE-Coursework

Recommended visibility: Private during development.

## Branch Strategy
main = stable final version only.

Each member works in their own branch:
- maleesha-auth-dashboard
- denuawan-routes-schedules
- dinethi-drivers-vehicles-reports

## Daily Workflow
1. Pull latest main.
2. Switch to your branch.
3. Code your assigned module.
4. Commit with a meaningful message.
5. Push to GitHub.
6. Update the group with progress.

## Pull Request Rules
Before merging:
- Code must run without errors.
- Screenshots should be added if UI changed.
- Another member should review.
- Merge only after review.
