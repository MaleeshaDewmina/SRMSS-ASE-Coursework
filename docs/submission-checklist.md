# Final Submission Checklist

## Group Deliverables
- Group report
- GitHub link
- Working web application
- UML diagrams
- User manual
- Testing evidence
- Group presentation slides

## Individual Deliverables
- Individual implemented components
- Individual testing evidence
- Individual reflection
- Individual 5-minute recorded demo

## Final Checks
- All members' names and IDs included
- Report word count checked
- GitHub repository organized
- Screenshots added
- Application runs correctly
- Presentation prepared
- Videos recorded
