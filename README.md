# Smart Route Management and Scheduling System (SRMSS)

## Project Overview
SRMSS is a web-based system developed for public transport depots to manage routes, drivers, vehicles, schedules, fuel logs, maintenance logs, reports, and dashboard analytics.

This project is developed for CS6003 Advanced Software Engineering Coursework 01.
