# Contribution Guide

## Workflow
1. Pull latest changes from main.
2. Work only on your own branch.
3. Commit regularly with clear messages.
4. Push your branch.
5. Create a Pull Request to main.
6. Another member reviews before merging.

## Branch Names
- maleesha-auth-dashboard
- denuawan-routes-schedules
- dinethi-drivers-vehicles-reports

## Commit Message Format
Use clear commit messages.

Examples:
- Add login page UI
- Implement route create function
- Fix schedule conflict validation
- Add vehicle management model
- Update testing evidence table

## Rules
- Do not push broken code to main.
- Do not edit another member's module without informing them.
- Keep documentation updated.
- Test your module before creating a Pull Request.
